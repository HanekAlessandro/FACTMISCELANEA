# Sistema de Facturación - Miscelánea

Proyecto desarrollado en ASP.NET Core Razor Pages y SQL Server.

## Tecnologías
- ASP.NET Core 8
- SQL Server
- Razor Pages
- Bootstrap 5
- Entity Framework Core

## Funciones
- Gestión de productos
- Gestión de clientes
- Facturación
- Control de inventario
- Reportes

## Cómo ejecutar el proyecto

```bash
dotnet restore
dotnet run
```
